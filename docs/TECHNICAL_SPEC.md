# Metro New Partnerly — техническое задание

## Продукт
Отдельная платформа для каталога Discord-серверов, взаимной рекламы и партнёрств. Репозиторий: kirill12633/partnerly.metro.new.

## Дизайн
Светлый минималистичный интерфейс, белый фон, синий и голубой акценты, мягкие тени. Автоматическая адаптация для телефона, планшета и компьютера. Русский и английский сейчас; архитектура должна позволять добавлять языки. Каталог доступен без входа.

## Авторизация
Вход только через Discord OAuth2, без пароля. При первом входе требуется согласие с правилами. Добавление серверов и отправка партнёрских предложений доступны после входа. Проверка прав на Discord guild выполняется сервером через Discord API: owner или MANAGE_GUILD/ADMINISTRATOR. Нельзя доверять данным о правах, присланным браузером. Обычный пользователь может предложить сервер на модерацию.

## Каталог
Категории: Игры, Общение, Minecraft, Ролевые игры (RP), Программирование, Обучение, Творчество, Сообщества, Другое.
Фильтры: категория, участники, число партнёров, VIP, открыт для партнёрства, дата публикации, популярность. Поиск по названию, описанию, категории, тематике и тегам.

## Личный кабинет
Мой профиль, Мои серверы, Мои партнёрства, Достижения, Мой VIP, Настройки, История активности, Уведомления, Избранное. Статистика: просмотры, партнёры, входящие предложения, принятые/отклонённые, популярность, графики за неделю и месяц.

## Партнёрства
Встроенный чат не нужен. Владелец выбирает способы контакта: Discord DM, бот и/или приглашение на сервер. Успешные партнёрства учитываются только после подтверждения. Уведомления показываются на сайте и через Discord-бота.

## Модерация и безопасность
Статусы сервера: pending, published, rejected, hidden, closed. Жалобы на серверы и пользователей: new, reviewing, confirmed, dismissed; причина, описание и ссылка на доказательство. Защита от спама, дублей заявок, некорректных Discord-ссылок и подозрительной активности. Отдельная страница правил и обязательное согласие при регистрации.

## Роли и админ-панель
Роли: владелец, администратор, главный модератор, модератор. Роли выдаются отдельно в базе. Разделы: статистика, пользователи, серверы, предложения, жалобы, VIP, достижения, модераторы, категории, журнал действий, настройки.

## VIP и достижения
VIP выдаётся администрацией вручную или за полезную активность; платёжная интеграция не входит в первый этап. Преимущества: оформление карточки, значок/рамка, приоритет каталога, расширенная статистика. Достижения: первый сервер; 5/10/25/50 подтверждённых партнёрств; помощь проекту; активность; приглашение пользователей.

## Инфраструктура
Cloudflare Workers для API, D1 для данных. Ежедневное резервное копирование настраивается в Cloudflare и проверяется тестовым восстановлением. OAuth Client Secret и bot token хранятся только в Worker Secrets. Для запуска потребуется создать D1, Discord Application и настроить OAuth Redirect URI.

## Этапы
1. Начальный интерфейс, Worker, схема D1.
2. Discord OAuth2, сессии и принятие правил.
3. Каталог, поиск, фильтры, избранное.
4. Добавление серверов, проверка прав, модерация.
5. Предложения о партнёрстве и контакты.
6. Личный кабинет, достижения, VIP, уведомления.
7. Админ-панель, жалобы, журнал действий, антиспам.
8. Проверка безопасности, backup и deployment.

## Состояние стартового коммита
Это стартовый каркас: базовый API чтения каталога и схема БД. OAuth2, бот, запись данных, кабинет и админ-панель ещё не реализованы и требуют настройки внешних ресурсов/секретов.
